# NEXUS Studio Website

A responsive, single-page website for NEXUS Studio, built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `NEXUS_Studio_Website` folder in VS Code (or another code editor).
3. Open `index.html` in a browser. For a smoother development workflow, use the VS Code Live Server extension.

No build tools or package installation are required.

## Project structure
- `index.html` — page content and sections
- `styles.css` — responsive styling and visual design
- `script.js` — mobile navigation and current year
- `assets/nexus-mark.svg` — geometric NEXUS mark

## Before publishing
- Confirm both team members approve the public bios and contact details.
- Replace the initials-based profile artwork with approved portraits if desired.
- Add approved LearnSphere screenshots when available.
- Confirm the college name and any institutional branding are appropriate to publish.
- The site currently uses a `mailto:` link for the team email; it does not include a contact form or backend.
- Google Fonts are loaded online. The site still has fallback fonts if unavailable.

## Edit the content
Open `index.html` and search for the text you want to update. Colors are defined near the top of `styles.css` in the `:root` variables.
